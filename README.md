# «Внимание! Производится посадка на скорый поезд…»

Интерактивное задание для «Разговоров о важном» (СПО, 2–4 курсы).

**Задание:** выбери верные факты о железных дорогах России и отправься в путешествие (хотя бы виртуально).

- 13 фактов на билетах: 8 верных и 5 ложных; порядок билетов перемешивается при каждом запуске.
- Верный билет получает штамп «Верно», улетает в картинку, и история продвигается на один кадр (от вокзала до «Счастливого пути!»).
- Ложный билет рвётся пополам, а под ним появляется правда.
- Звук объявления на вокзале звучит только в финале.

## Как открыть

| Что нужно | Что взять |
|---|---|
| Открыть без интернета, с флешки, отправить файлом | **`index.html`** в корне: один файл, всё уже внутри (картинки, звук, код) |
| Открыть онлайн | ссылка GitHub Pages: `https://<логин>.github.io/<репозиторий>/` |
| Поправить тексты, картинки или оформление | папка **`src/`** |

## Как поправить

```
src/
  facts.js      ← ТЕКСТЫ: заголовок, задание, факты, пояснения, подписи к кадрам
  index.html    ← разметка
  style.css     ← оформление (цвета — в самом начале файла)
  app.js        ← логика
  img/kadr1…9.webp   ← кадры истории (1 — старт, 9 — финал)
  audio/obyavlenie.mp3
originals/      ← исходные картинки (раскадровка 3×3 и образец билетов)
build.py        ← собирает src/ в один файл index.html
```

1. Откройте `src/facts.js` в Блокноте или VS Code и поменяйте тексты. У каждого факта есть `ok: true` (верный) или `ok: false` (ложный) и `note`, то есть пояснение. Сохраняйте в UTF-8.
2. Проверьте результат: откройте `src/index.html` двойным кликом, он работает и без сборки.
3. Соберите один файл: `python build.py` (нужен Python 3, без дополнительных библиотек). Получится обновлённый `index.html` в корне.

Чтобы заменить картинку, положите новый файл с тем же именем в `src/img/` (горизонтальный, 3:2, например 960×640) и запустите `python build.py`.

Число верных фактов можно менять: кадры распределятся по ответам автоматически. Кадров ровно 9: старт и 8 шагов.

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save. Через минуту-две интерактив появится по адресу `https://<логин>.github.io/<репозиторий>/`.
